# Формат описания Data Flow: «Запрос-Цепочка»

При автоматическом заполнении дочерней страницы **«API-Контракты и Поток данных» (API-Contracts & Data Flow)**:

1. Раздел **API-Контракты размещается СТРОГО ДО Потока данных (Data Flow)**.
2. Для **каждого отдельного графика тренда** и для **каждой отдельной таблицы** пишется персональная секция с API-Контрактом и соответствующей Запрос-Цепочкой.

## Правило формата

Формат «Запрос-Цепочка» отражает последовательность выполнения бизнес-сценария от инициации на клиенте до финального результата, с явным указанием передаваемых и возвращаемых данных на каждом шаге.

### Структура записи

```text
Цепочка: [Название сценария] — [Краткая суть бизнес-процесса].

1. METHOD /endpoint?params = [Компактный ответ]
-- Комментарий (если необходим)
2. METHOD /endpoint + {передаваемое тело} = {возвращаемое тело}
...
```

---

## Пример записи Запроса-Цепочки

**Цепочка:** Бронирование столика — поиск кафе в городе, бронь места на 2 персоны и внесение депозита.

1. `GET /api/v1/Places?city=spb` = `[{"cafe": "Mysteria"}, {"cafe": "На Невском"}, ...]`
   -- Загрузка списка всех мест
2. `POST /api/v1/Tables/reserve` + `{"cafe": "Mysteria", "seats": 2}` = `{"ticket": "seat-42"}`
   -- Загрузка Бронируем столик на 2 места
3. `POST /api/v1/Orders/pay` + `{"ticket": "seat-42", "tip": 100}` = `{"status": "paid"}`
