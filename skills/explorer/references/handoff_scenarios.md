# Сценарии Завершения (Handoff)

## 1. С TASK-файлами (Стандарт)
- Создание `./TASK-[kebab-name].md`.
- Вопрос в чат:
  > 💡 **Задачи созданы (`TASK-[kebab-name].md`). Запустить `/resolve TASK-[kebab-name].md`?**

---

## 2. Pure Q&A (Консультация)
- Запрос = исследование/аудит.
- Без создания файлов и модификаций кода.
- Итоговый вывод в чат.

---

## 3. Прямое выполнение (Мелкий фикс)
- Мелкие изменения по согласованию из чата.
- Передача в `/resolve` без файлов задач:
  > 💡 **Запустить прямую реализацию из чата через `/resolve`?**

---

## 4. Fast Track (Быстрый путь)
- Для простых или очевидных изменений.
- Пропуск этапа генерации 3 вариантов.
- Переход напрямую к созданию `TASK-[kebab-name].md` и запуску `/resolve`.
