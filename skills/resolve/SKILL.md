Авто-реализация задач (фичи, адаптеры, модули, фиксы багов) из текста в чате или `TASK-[имя].md` в корне.
Режим: **100% авто** без step-by-step и промежуточных опросов.

---

## 🔑 Ключевые Правила

1. **Неоднозначность** → СТРОГО стоп → точечный вопрос пользователю.
2. **Финальный опрос** → спросить о вызове `/check`.

---

## 📋 Порядок Выполнения

1. **Определение задачи**:
   - Чтение чата / `TASK-[имя].md` → [task_format.md](references/task_format.md).
2. **Валидация требований**:
   - Непонятно/двояко → стоп → уточнение у юзера.
3. **Кодинг и авто-проверка**:
   - Лог в чат: `«Выполняю: [краткое описание этапа]»`.
   - Соблюдение архитектуры, cleanup и Zero Dead Code → [coding_directives.md](references/coding_directives.md).
   - Проверка типов/линтинг: `npm run lint`, `npx tsc --noEmit`.
4. **Обновление статуса**:
   - Отметка `[x]` в `TASK-[имя].md`.
5. **Завершение**:
   - Опрос юзера:
     > ❓ **Реализация задачи завершена. Желаете запустить финальную проверку и технический аудит проекта через навык `/check`?**
   - Да → вызов `/check` (авто-фикс багов через `debug`).
   - Краткий финальный отчёт.
