# Формат и Источники Задач (resolve)

## 1. Источники

- **Текст в чате** (`/resolve ...`): использование описания из чата. При необходимости → фиксация в `TASK-[имя].md` → старт авто-реализации.
- **Файл `TASK-[имя].md`**: чтение структуры из указанного файла.
- **Мульти-планы**: при нескольких `TASK-*.md` без явного указания → автовыбор последнего по `mtime`.

---

## 2. Структура `TASK-[имя-фичи].md`

Единственный файл `TASK-[имя-фичи].md` в корне:

```markdown
# TASK-[имя-фичи].md: [Название задачи]

## Общие сведения
- **Имя задачи**: `[имя-фичи]`
- **Назначение**: [Краткое описание]
- **Общий статус**: В процессе выполнения
- **Первичное выполнение**: [ ]

## Чек-лист шагов

- [ ] **Шаг 1: [Название шага]**
  - **Цель**: [Конкретный результат]
  - **Файлы для изменений**: `src/...`
```
