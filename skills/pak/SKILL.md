name: pak
description: >
  Навык для блокировки (бандлинга/минимизации) или разблокировки (распаковки) директорий (плагинов/модулей) для скрытия кода от ИИ-агентов.
  Принимает путь к целевой директории.
  Если директория распакована -> компилирует её в index.js, архивирует оригиналы в .archives/ и удаляет их.
  Если заблокирована -> восстанавливает оригиналы из последнего архива в .archives/.
  Триггеры: /pak, "заблокируй плагин", "разблокируй плагин", "выполни pak", "изолируй плагин", "заблокируй директорию", "разблокируй директорию".
---

Навык **pak** переключает режим директории: **изолированный** (бандл + `index.d.ts`) ↔ **открытый** (исходники).

> [!WARNING]
> **СТРОЖАЙШИЙ ЗАПРЕТ АВТО-ВЫЗОВА И РАСПАКОВКИ**
>
> - **СТРОГО ЗАПРЕЩЕНО** выполнять `pack`/`unpack` или запускать `pak-toggle.cjs` без предварительного явного согласия пользователя в чате.
> - **НЕ триггерить** при упоминании/передаче путей.
> - **Вызов строго по**: явной команде `/pak` или прямому текстовому запросу на (раз)блокировку.

## 1. Команды CLI

Запуск через Node.js скрипт навыка:

- **Статус** (`bundled` | `unbundled`):
  ```bash
  node .agents/skills/pak/pak-toggle.cjs status <путь-к-директории>
  ```
- **Блокировка / Бандлинг**:
  ```bash
  node .agents/skills/pak/pak-toggle.cjs pack <путь-к-директории> [флаг_сохранения]
  ```
  *Прим.: Добавление флага (например, `-arh`, `архив`, `-a`, `дамп`, `-dump`, `backup`, `keep`, `save` и др.) выполняет упаковку без удаления исходных файлов.*
- **Разблокировка / Восстановление**:
  ```bash
  node .agents/skills/pak/pak-toggle.cjs unpack <путь-к-директории> [ревизия]
  ```
  *Прим.: В качестве `[ревизия]` можно передать индекс (например, `0`, `1`), хэш (например, `abc1234`) или таймстемп (`260826100923819`). Если параметр опущен, восстанавливается последняя версия.*
- **Просмотр истории**:
  ```bash
  node .agents/skills/pak/pak-toggle.cjs log <путь-к-директории>
  ```

## 2. Алгоритм при вызове /pak

1. **Резолв пути**: целевая директория (при `guide.md` → родительская папка).
2. **Проверка**: `node ... status <путь>` → получение статуса (`bundled` / `unbundled`).
3. **Переключение**: вызов `pack` (если `unbundled`) или `unpack` (если `bundled`) БЕЗ доп. подтверждения.
4. **Отчёт**: вывод результата в чат.

## 3. Генерация контрактов типов (`index.d.ts`)

При `pack` генерируется `index.d.ts` из `types.ts` и исходников:

- **TS AST-парсинг**: точный сбор `type`, `interface`, `enum` без обрезки многострочных структур.
- **Резолв зависимостей**: сканирование всех файлов ядра `model/` (типы, функции, константы, контексты) и сохранение импортов в `index.d.ts` для защиты от ложной очистки Dead Code.
- **Валидация синтаксиса**: проверка структуры перед записью `index.d.ts`.
- **Экспорт API**: сигнатуры функций, фабрик плагинов и методов API.
- **Строгий контракт**: единственный источник типов для ИИ-агента и tsc в заблокированном режиме.
