# 🧩 Контекст проекта

- **Суть**: Веб-приложение для конвертации 3D FBX-моделей с анимациями в запеченный растровый SpriteSheet (Multi-animation Atlas: PNG + JSON). Включает загрузчик FBX, управление камерой и воспроизведением, запекание кадров и экспорт атласа.
- **Стек**: React + Three.js (@react-three/fiber, @react-three/drei), TypeScript, Zustand, TailwindCSS, Vite.
